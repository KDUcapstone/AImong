# 🏠 홈 화면 API v2.1

> **버전**: v2.1  \|  **수정일**: 2026-05-10  \|  **적용 범위**: 앱 부팅, 홈 요약, 에너지, 스트릭 캘린더
> 

> 🆕 **v2.1 반영**: 앱 실행 직후 초기 상태 판단용 `GET /app/bootstrap`과 홈 외 화면에서 사용하는 `GET /energy`를 추가합니다.
> 

> 🆕 **v2.0 반영**: 홈 화면의 오늘 학습 추천과 완료 수는 `missionId`가 아니라 `setId` 기준입니다. 기존 `missionSummary` 명칭은 화면 호환을 위해 유지할 수 있지만, 내부 의미는 "학습 세트 요약"입니다.
> 

> ℹ️ **모든 엔드포인트는 CHILD 인증(JWT)이 필요합니다.**
> 

> 홈 화면 API는 앱 첫 진입/탭 복귀 시 필요한 요약 데이터를 한 번에 내려주는 **읽기 전용 aggregate API**입니다. 보상 수령, 미션 제출, 펫 장착 변경 같은 상태 변경은 각 도메인 API에서만 처리합니다.
> 

## GET /app/bootstrap

> 앱 실행 직후 초기 상태 조회 — 자동 로그인, 첫 화면 라우팅, 서버 시간, 앱 버전 정책 확인용
> 

**담당**: BE (문한일) \| **인증**: 선택 (없음/PARENT/CHILD)

> ⚠️ Authorization 헤더가 없으면 게스트 상태로 반환합니다. 토큰이 있으면 PARENT 또는 CHILD로 검증하고, 실패 시 401을 반환합니다.
>

| 상황 | HTTP | code | message |
| --- | --- | --- | --- |

```jsx
4. CHILD 응답은 홈 진입 가능 여부만 알려주고, 실제 홈 요약은 GET /home에서 조회
5. minimumAppVersion/forceUpdateRequired는 서버 설정값 또는 상수로 관리
```

## 홈 화면 UI / 이동 계약

> 이미지 시안 기준: 상단 상태칩 4개(에너지, XP, 뽑기 티켓, 스트릭) + 학습 경로형 미션 노드 + 하단 탭 네비게이션으로 구성합니다.
> 

| UI 요소 | 표시 데이터 | 탭 액션 |
| --- | --- | --- |
| 에너지 칩 | `topStatus.energy` | 현재는 이동 없음. 추후 하트/쉴드 설명 팝업 연결 가능 |
| XP 칩 | `topStatus.xp` | 현재는 이동 없음 |
| 뽑기 티켓 칩 | `topStatus.ticketCount` | 가챠 화면(`/gacha`)으로 이동. 별도 API 호출 없음 |
| 스트릭 칩 | `topStatus.streakDays`  • "일" | `GET /home/streak-calendar` 호출 후 내가 완료한 날짜 캘린더/바텀시트 표시 |
| 시작 버튼 | `missionSummary.recommendedMission` | `GET /mission-sets/{setId}/questions`로 이동. `recommendedMission`이 null이면 비활성 |
| 복습 노드 | `recommendedMission.isReviewable=true`인 세트 또는 완료 세트 | 해당 세트의 questions API 호출 시 review 모드로 진행 |

## GET /energy

> 에너지 현재 상태 단독 조회 — 학습맵/미션 진입/상점 등 홈 외 화면에서 사용
> 

**담당**: BE (문한일) \| **인증**: CHILD

**Response 200**

```json
{
  "success": true,
  "data": {
    "energy": 15,
    "maxEnergy": 20,
    "nextEnergyRecoverAt": "2026-05-10T09:10:00Z",
    "fullRecoverAt": "2026-05-10T10:00:00Z",
    "recoverIntervalMinutes": 10,
    "missionStartCost": 5
  }
}
```

**구현 노트**

```jsx
1. CHILD JWT 검증 → childId 추출
2. child_profiles.energy, energy_recovered_at 기준으로 lazy recovery 계산
3. maxEnergy=20, recoverIntervalMinutes=10, missionStartCost=5를 서버 정책값으로 반환
4. energy가 maxEnergy이면 nextEnergyRecoverAt/fullRecoverAt은 null 가능
5. 일반 모드 학습 세트 시작 시에만 energy 차감. 복습 모드는 차감 없음
```

## GET /home/streak-calendar

> 스트릭 칩 클릭 시 내가 미션을 완료한 날짜 목록 조회 — 월 단위 캘린더/바텀시트 표시용
> 

**담당**: BE (문한일) | **인증**: CHILD

**Query Parameters**

| 파라미터 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| yearMonth | string | 선택 | `YYYY-MM`. 생략 시 KST 기준 현재 월 |

**Response 200**

```json
{
  "success": true,
  "data": {
    "yearMonth": "2026-05",
    "continuousDays": 5,
    "completedDates": [
      "2026-05-01",
      "2026-05-02",
      "2026-05-03"
    ],
    "today": "2026-05-03"
  },
  "requestId": "req_01HXYZABC123"
}
```

**구현 기준**

```jsx
1. yearMonth가 없으면 LocalDate.now(Asia/Seoul)의 YYYY-MM 사용
2. 해당 월의 시작일~다음 달 시작일 범위 계산
3. mission_daily_progress에서 child_id + progress_date between start/end 조회. 해당 날짜에 일반 모드로 통과한 세트가 1개 이상이면 completedDates에 포함
4. 중복 제거 후 오름차순 정렬해 completedDates 반환
5. 복습만 수행한 날짜는 포함하지 않음
```

## 응답 필드 규칙

| 필드 | 규칙 |
| --- | --- |
| serverDate | KST 기준 오늘 날짜. FE는 홈 화면 날짜/자정 갱신 판단에 사용 |
| [topStatus.energy](http://topStatus.energy) | 상단 에너지 표시값. 계정 단위 에너지 현재값이며 최대 20이다. 일반 모드 학습 세트 시작 시 5 차감, 10분마다 1 회복한다. 퀴즈 화면의 오답 차감 하트(lives)는 세션 내부 UI이며 이 값과 동기화하지 않는다. |
| topStatus.maxEnergy | 에너지 최대값. 현재 정책은 20 고정 |
| topStatus.nextEnergyRecoverAt | 다음 에너지 1 회복 예정 시각. energy가 이미 20이면 null 가능 |
| topStatus.xp | 상단 번개 칩 표시값. `profile.totalXp`와 동일 |
| topStatus.ticketCount | 상단 티켓 칩 표시값. NORMAL/RARE/EPIC 미사용 티켓 합계 |
| topStatus.streakDays | 상단 스트릭 칩 표시값. `streak.continuousDays`와 동일 |
| profile.todayXp | `child_profiles.today_xp` 기준. KST 자정 리셋 대상 |
| profile.weeklyXp | child_profiles.weekly_xp 기준. KST 월요일 00:00 리셋 대상 |
| equippedPet | child_profiles.equipped_pet_id 기준. 장착 펫 없으면 null |
| missionSummary.todayCompletedCount | 오늘 KST 기준 `is_review=false`, `is_passed=true` 완료 학습 세트 수. 신규 구현에서는 `todaySetCount` 별칭 권장 |
| missionSummary.todayTargetCount | MVP 기본값 3. 기획 변경 전까지 서버 상수로 고정 |
| missionSummary.canStartMission | 장착 펫이 있고, 추천 가능한 잠금 해제 미션이 있으면 true |
| missionSummary.recommendedMission | 잠금 해제 + 오늘 미완료 세트 중 level/stage/displayOrder 오름차순 첫 번째. 없으면 복습 가능한 최근 완료 세트 또는 null |
| streak.todayMissionCount | `GET /streak`와 동일. lastCompletedDate != today(KST)이면 0 반환 |
| streak.partner | 파트너 없으면 null. 빈 객체 금지 |
| dailyQuestSummary.claimableCount | MANUAL 퀘스트 중 completed=true AND rewardClaimed=false 개수 |
| returnReward | `GET /return-reward`와 동일한 판정. 홈 조회만으로 보상 지급하지 않음 |
| tickets | tickets.used_at IS NULL인 row-per-ticket 보유 수 |

## 구현 노트

```jsx
1. CHILD JWT 검증 후 childId 추출
2. today = LocalDate.now(Asia/Seoul), weekStart = today.with(MONDAY)
3. child_profiles 조회 후 energy/energy_recovered_at 기준 10분당 1 회복분을 lazy 반영해 topStatus.energy 구성
4. equipped_pet_id가 있으면 pets에서 장착 펫 조회
5. mission_attempts / mission_daily_progress 기준 오늘 완료 세트 수 계산
6. mission_sets + mission_set_progress 기준 추천 세트 1개 선택
7. streak_records + child_profiles.shield_count + friend_streaks 기준 streak 요약 구성
8. daily_quest_progress 기준 오늘 퀘스트 요약 구성
9. return_reward_claims + streak_records.last_completed_date 기준 복귀 보상 가능 여부만 계산
10. tickets에서 used_at IS NULL인 티켓 수를 type별 집계
11. 모든 하위 데이터는 같은 트랜잭션의 readOnly 조회로 구성
```

## Spring Boot 구현 가이드

> ⚠️ **v2.0 구현 시 주의**: 아래 코드 예시는 기존 `Mission*` 클래스명을 포함할 수 있습니다. 실제 구현에서는 추천/완료/조회 쿼리를 `mission_sets`, `mission_set_progress`, `set_id` 기준으로 작성하고, 기존 `MissionDto` 명칭을 유지하더라도 payload에는 `setId`, `levelNo`, `difficulty`를 포함해야 합니다.
> 

### Controller

```java
@RestController
@RequiredArgsConstructor
public class HomeController {

    private final HomeService homeService;

    @GetMapping("/home")
    public ApiResponse<HomeResponse> getHome(
            @RequestAttribute("childId") UUID childId
    ) {
        return ApiResponse.success(homeService.getHome(childId));
    }

    @GetMapping("/home/streak-calendar")
    public ApiResponse<StreakCalendarResponse> getStreakCalendar(
            @RequestAttribute("childId") UUID childId,
            @RequestParam(required = false) String yearMonth
    ) {
        return ApiResponse.success(homeService.getStreakCalendar(childId, yearMonth));
    }
}
```

### Service

```java
@Service
@RequiredArgsConstructor
public class HomeService {

    private static final int TODAY_TARGET_COUNT = 3;
    private static final ZoneId KST = ZoneId.of("Asia/Seoul");

    private final ChildProfileRepository childRepo;
    private final PetRepository petRepo;
    private final MissionRepository missionRepo;
    private final MissionAttemptRepository missionAttemptRepo;
    private final MissionDailyProgressRepository missionDailyProgressRepo;
    private final StreakRecordRepository streakRepo;
    private final FriendStreakRepository friendStreakRepo;
    private final DailyQuestProgressRepository dailyQuestRepo;
    private final ReturnRewardClaimRepository returnRewardClaimRepo;
    private final TicketRepository ticketRepo;

    @Transactional(readOnly = true)
    public HomeResponse getHome(UUID childId) {
        LocalDate today = LocalDate.now(KST);
        Instant todayStart = today.atStartOfDay(KST).toInstant();
        Instant tomorrowStart = today.plusDays(1).atStartOfDay(KST).toInstant();

        ChildProfile child = childRepo.findById(childId)
            .orElseThrow(() -> new AImongException(ErrorCode.NOT_FOUND, "자녀 프로필을 찾을 수 없습니다"));

        PetDto equippedPet = child.getEquippedPetId() == null
            ? null
            : petRepo.findByIdAndChildId(child.getEquippedPetId(), childId)
                .map(PetDto::from)
                .orElse(null);

        int todayCompletedCount = missionAttemptRepo.countTodayCompletedMissions(
            childId, todayStart, tomorrowStart);

        MissionDto recommendedMission = findRecommendedMission(childId, today);

        HomeMissionSummary missionSummary = new HomeMissionSummary(
            todayCompletedCount,
            TODAY_TARGET_COUNT,
            equippedPet != null && recommendedMission != null,
            recommendedMission
        );

        HomeStreakDto streak = buildStreak(child, today);
        HomeDailyQuestSummary questSummary = buildDailyQuestSummary(childId, today);
        HomeReturnRewardDto returnReward = buildReturnReward(childId, today);
        TicketSummary tickets = ticketRepo.countUnusedTickets(childId);
        HomeTopStatus topStatus = new HomeTopStatus(
            child.getShieldCount(),
            child.getTotalXp(),
            tickets.totalCount(),
            streak.continuousDays()
        );

        return HomeResponse.builder()
            .serverDate(today)
            .topStatus(topStatus)
            .profile(HomeProfileDto.from(child))
            .equippedPet(equippedPet)
            .missionSummary(missionSummary)
            .streak(streak)
            .dailyQuestSummary(questSummary)
            .returnReward(returnReward)
            .tickets(tickets)
            .build();
    }

    @Transactional(readOnly = true)
    public StreakCalendarResponse getStreakCalendar(UUID childId, String yearMonth) {
        YearMonth targetMonth = yearMonth == null || yearMonth.isBlank()
            ? YearMonth.now(KST)
            : YearMonth.parse(yearMonth);

        LocalDate start = targetMonth.atDay(1);
        LocalDate endExclusive = targetMonth.plusMonths(1).atDay(1);

        List<LocalDate> completedDates = missionDailyProgressRepo
            .findCompletedDatesByChildIdAndDateBetween(childId, start, endExclusive);

        int continuousDays = streakRepo.findById(childId)
            .map(StreakRecord::getContinuousDays)
            .orElse(0);

        return new StreakCalendarResponse(
            targetMonth.toString(),
            continuousDays,
            completedDates,
            LocalDate.now(KST)
        );
    }
}
```

### 추천 미션 선택 규칙

```java
private MissionDto findRecommendedMission(UUID childId, LocalDate today) {
    StageProgress progress = missionAttemptRepo.getStageProgress(childId);

    List<Mission> unlocked = missionRepo.findAllOrderByStageAscSortOrderAsc().stream()
        .filter(m -> isUnlocked(m.getStage(), progress))
        .toList();

    Set<UUID> todayCompletedMissionIds = missionDailyProgressRepo
        .findMissionIdsByChildIdAndDate(childId, today);

    return unlocked.stream()
        .filter(m -> !todayCompletedMissionIds.contains(m.getMissionId()))
        .findFirst()
        .map(m -> MissionDto.of(m, false))
        .orElseGet(() -> unlocked.stream()
            .filter(m -> missionAttemptRepo.existsFirstComplete(childId, m.getMissionId()))
            .findFirst()
            .map(m -> MissionDto.of(m, true))
            .orElse(null));
}

private boolean isUnlocked(int stage, StageProgress progress) {
    return switch (stage) {
        case 1 -> true;
        case 2 -> progress.stage1Completed() >= 3;
        case 3 -> progress.stage2Completed() >= 4;
        default -> false;
    };
}
```

## 주의사항

| 항목 | 설명 |
| --- | --- |
| 조회 전용 | `GET /home`은 어떤 보상도 자동 수령하지 않으며 DB 상태를 변경하지 않음 |
| KST 기준 | 오늘 미션, 데일리 퀘스트, 스트릭, 복귀 보상 계산은 모두 Asia/Seoul 기준 |
| 복습 제외 | 오늘 완료 수와 추천 미션 진행도는 `is_review=false` 기준 |
| N+1 방지 | 홈 API는 앱 첫 진입 경로이므로 필요한 요약 쿼리를 전용 Repository 메서드로 분리 |
| 부분 실패 금지 | 하위 도메인 데이터 일부 조회 실패 시 빈 객체로 숨기지 말고 원인에 맞는 서버 오류로 처리 |
