# 💌 복귀 보상 API

## GET /return-reward

> 복귀 보상 확인 — 앱 오픈 시 호출, 자동 지급 아님
> 

**담당**: BE (문한일) | **인증**: CHILD

> 🆕 **v1.1 변경**: 중복 지급 방지 기준이 **"오늘 수령 여부"에서 "같은 결석 구간 수령 여부"** 로 변경.
> 

**Response 200 (보상 있음)**

```json
{
  "success": true,
  "data": {
    "hasReward": true,
    "daysMissed": 4,
    "ticketCount": 2,
    "message": "4일 만에 돌아왜어요! 🎉 티켓 2장 드릴게요!"
  }
}
```

**Response 200 (보상 없음)**

```json
{ "success": true, "data": { "hasReward": false } }
```

**구현 노트**

```jsx
baseDate = streak_records.last_completed_date
if baseDate == null:
  hasReward = false
else:
  daysMissed = today(KST) - baseDate
  ticketCount = min(daysMissed - 2, 3)
  if daysMissed <= 2:
    hasReward = false
  else if exists return_reward_claims(child_id, base_last_completed_date = baseDate):
    hasReward = false  ← v1.1 변경: 날짜 기준 → 결석 구간 기준
  else:
    hasReward = true
```

## POST /return-reward/claim

> 복귀 보상 수령
> 

**담당**: BE (문한일) | **인증**: CHILD

**Response 200**

```json
{
  "success": true,
  "data": {
    "rewards": [
      { "type": "TICKET", "ticketType": "NORMAL", "count": 2, "reason": "RETURN_REWARD" }
    ],
    "remainingTickets": { "normal": 5 }
  }
}
```

**예외 처리**

| 상황 | HTTP | code | message |
| --- | --- | --- | --- |
| 복귀 보상 조건 미충족 (3일 미만 또는 미션 이력 없음) | 400 | BAD_REQUEST | 복귀 보상이 없어요 |
| 같은 결석 구간에 대한 보상 이미 수령 | 409 | CONFLICT | 이미 보상을 받았어요 |

**구현 노트**

```jsx
1. GET /return-reward와 동일한 조건으로 재검증
2. 트랜잭션 시작
3. return_reward_claims에 (child_id, base_last_completed_date) UNIQUE INSERT  ← v1.1
4. NORMAL 티켓 row를 ticketCount만큼 INSERT
5. 커밋
```

## 🔧 Spring Boot 구현 가이드

### Entity & DB 구조

```java
// return_reward_claims 테이블
@Entity
@Table(
    name = "return_reward_claims",
    uniqueConstraints = @UniqueConstraint(
        columnNames = {"child_id", "base_last_completed_date"}
    )
)
public class ReturnRewardClaim {
    @Id @GeneratedValue
    private UUID id;

    @Column(name = "child_id", nullable = false)
    private UUID childId;

    // 결석 구간 식별 기준: streak_records.last_completed_date 값
    @Column(name = "base_last_completed_date", nullable = false)
    private LocalDate baseLastCompletedDate;

    @Column(name = "claimed_at", nullable = false)
    private Instant claimedAt = Instant.now();
}

// tickets 테이블 (인증 API에서 정의된 Entity 재사용)
// ticket_id | child_id | ticket_type | used_at (row-per-ticket 모델)
```

### Service 로직

```java
@Service
@RequiredArgsConstructor
public class ReturnRewardService {

    private final StreakRecordRepository streakRepo;
    private final ReturnRewardClaimRepository claimRepo;
    private final TicketRepository ticketRepo;

    // ─── GET /return-reward ───────────────────────────
    public ReturnRewardResponse getReturnReward(UUID childId) {
        StreakRecord streak = streakRepo.findByChildId(childId)
            .orElseThrow(() -> new AImongException(ErrorCode.NOT_FOUND));

        LocalDate baseDate = streak.getLastCompletedDate(); // last_completed_date
        if (baseDate == null) {
            return ReturnRewardResponse.noReward();
        }

        LocalDate today = LocalDate.now(ZoneId.of("Asia/Seoul")); // KST 기준!
        long daysMissed = ChronoUnit.DAYS.between(baseDate, today);

        if (daysMissed <= 2) {
            return ReturnRewardResponse.noReward();
        }

        // v1.1: 날짜가 아닌 결석 구간 기준으로 중복 수령 여부 확인
        boolean alreadyClaimed = claimRepo
            .existsByChildIdAndBaseLastCompletedDate(childId, baseDate);
        if (alreadyClaimed) {
            return ReturnRewardResponse.noReward();
        }

        int ticketCount = (int) Math.min(daysMissed - 2, 3);
        // 결석 3일→티켓 1장, 4일→2장, 5일 이상→3장(최대)
        return ReturnRewardResponse.hasReward(daysMissed, ticketCount);
    }

    // ─── POST /return-reward/claim ────────────────────
    @Transactional
    public ClaimResponse claimReturnReward(UUID childId) {
        // 1) GET과 동일 조건으로 재검증 (GET 이후 상태 변경 가능성)
        StreakRecord streak = streakRepo.findByChildId(childId)
            .orElseThrow(() -> new AImongException(ErrorCode.NOT_FOUND));

        LocalDate baseDate = streak.getLastCompletedDate();
        if (baseDate == null)
            throw new AImongException(ErrorCode.BAD_REQUEST, "복귀 보상이 없어요");

        LocalDate today = LocalDate.now(ZoneId.of("Asia/Seoul"));
        long daysMissed = ChronoUnit.DAYS.between(baseDate, today);
        if (daysMissed <= 2)
            throw new AImongException(ErrorCode.BAD_REQUEST, "복귀 보상이 없어요");

        // 2) 중복 수령 확인 → 409
        if (claimRepo.existsByChildIdAndBaseLastCompletedDate(childId, baseDate))
            throw new AImongException(ErrorCode.CONFLICT, "이미 보상을 받았어요");

        // 3) claim 레코드 INSERT (UNIQUE 제약이 DB 레벨 최후 방어선)
        ReturnRewardClaim claim = new ReturnRewardClaim();
        claim.setChildId(childId);
        claim.setBaseLastCompletedDate(baseDate);
        claimRepo.save(claim);

        // 4) row-per-ticket 모델로 NORMAL 티켓 지급
        int ticketCount = (int) Math.min(daysMissed - 2, 3);
        for (int i = 0; i < ticketCount; i++) {
            ticketRepo.save(new Ticket(childId, TicketType.NORMAL));
        }

        Map<String, Long> remaining = ticketRepo.countByChildIdGroupByType(childId);
        return ClaimResponse.of(ticketCount, remaining);
    }
}
```

### Repository

```java
public interface ReturnRewardClaimRepository extends JpaRepository<ReturnRewardClaim, UUID> {
    boolean existsByChildIdAndBaseLastCompletedDate(
        UUID childId, LocalDate baseLastCompletedDate
    );
}

public interface TicketRepository extends JpaRepository<Ticket, UUID> {
    @Query("""
        SELECT t.ticketType, COUNT(t)
        FROM Ticket t
        WHERE t.childId = :childId
          AND t.usedAt IS NULL
        GROUP BY t.ticketType
        """)
    Map<String, Long> countByChildIdGroupByType(@Param("childId") UUID childId);
}
```

### ⚠️ 주의사항

| 항목 | 설명 |
| --- | --- |
| KST 날짜 계산 | `LocalDate.now(ZoneId.of("Asia/Seoul"))` 필수. UTC 사용 시 자정 전후 1일 오차 발생 |
| UNIQUE 제약 | `(child_id, base_last_completed_date)` 복합 UNIQUE — DB 레벨 최후 중복 방지 |
| daysMissed 계산 | `baseDate`가 오늘이면 0, 어제면 1 — `daysMissed > 2` 조건이므로 3일 이상만 보상 |
| POST 재검증 필수 | GET 응답 후 다른 기기에서 먼저 수령할 수 있으므로 POST에서 반드시 조건 재확인 |
| ticketCount 범위 | 결석 3일→1장, 4일→2장, 5일+→3장 (최대 3장, `min(daysMissed-2, 3)`) |
