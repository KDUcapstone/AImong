# ⚙️ 재화 API v1.1

> **버전**: v1.1
> 

> **수정일**: 2026-05-16
> 

> **범위**: 톱니바퀴 잔액 조회, 미션 클리어 보상, 하트 회복, 스트릭 보호권 구매
> 

## 정책 요약

톱니바퀴(gear)는 에너지와 분리된 계정 단위 재화다. 일반 모드 미션 세트 클리어 성공 시 `gear +30`을 지급하고, MVP 사용처는 하트 0 상태에서 퀴즈 attempt를 1회 회복하는 것과 스트릭 보호권을 구매하는 것으로 제한한다.

## 비용 상수

| 항목 | 기본 비용 | 제한 |
| --- | --- | --- |
| 하트 회복 | 10 톱니바퀴 | 일반 모드 attempt당 1회 |
| 스트릭 보호권 구매 | 30 톱니바퀴 | 요청당 count 1 이상, 운영 정책에 따라 상한 가능 |

## GET /api/wallet

현재 자녀의 톱니바퀴 잔액과 주요 사용처 비용을 조회한다.

```json
{
  "success": true,
  "data": {
    "gear": 40,
    "costs": {
      "heartRevive": 10,
      "streakShield": 30
    }
  }
}
```

## 미션 클리어 보상

```
일반 모드 미션 세트 클리어 성공 시 gear +30 지급
currency_transactions.amount = +30
currency_transactions.reason = MISSION_CLEAR
ref_type = MISSION_ATTEMPT
ref_id = mission_attempts.attempt_id
```

## POST /api/mission-attempts/\{attemptId\}/revive

하트가 0이 된 진행 중 일반 모드 attempt를 톱니바퀴로 1회 회복한다. 세부 검증과 응답은 미션 / 퀴즈 API v2.10을 따른다.

## POST /api/streak/shields/purchase

톱니바퀴로 스트릭 보호권을 구매한다. 세부 검증과 응답은 스트릭 API를 따른다.

## 구현 원칙

- 모든 톱니바퀴 증감은 `child_profiles.gear`와 `currency_transactions`를 같은 트랜잭션에서 갱신한다.
- 미션 클리어 보상은 `MISSION_CLEAR`, 하트 회복은 `HEART_REVIVE`, 보호권 구매는 `STREAK_SHIELD_PURCHASE` 사유로 기록한다.
- 잔액 부족은 `409 GEAR_NOT_ENOUGH`로 반환한다.
- check API, 미션 실패, 에너지 추가, 하트 회복 자체는 톱니바퀴를 지급하지 않는다.
- 운영 보상 또는 테스트 지급이 필요하면 `ADMIN_ADJUST` 사유로 원장에 기록한다.
