# 👨‍👩‍👧 부모 대시보드 API

**통합 API v3.6 반영**: 부모 커스텀 퀘스트 관리 API와 단원별 보상 설정 API를 추가합니다. 부모 소유 자녀 검증은 기존 부모 대시보드 API와 동일하게 `parent_accounts.parent_id`(Firebase UID, String) 기준으로 수행합니다.

**v2.0 반영**: 부모 통계의 완료 수는 `setId` 기준 학습 세트 완료 수로 계산합니다. `incorrectRate`는 최종 submit으로 저장된 `mission_answer_results`만 기준으로 계산하며, 단일 문항 check 응답은 직접 반영하지 않습니다.

> ℹ️ **모든 엔드포인트는 PARENT 인증(Firebase ID Token)이 필요합니다.**
> 

> Firebase 토큰 → `parent_accounts.parent_id`(Firebase UID, String) 확인 → `child_profiles.parent_id` 일치 여부 검증 (불일치 시 403)
>

- `weeklyCompletedSetCount`, `totalCompletedSetCount`: `mission_attempts.is_review = false`, `is_passed = true`, `set_id` 최초 완료 기준

```json
        "rewardText": "놀이공원 가자!",
        "isTriggered": false,
        "triggeredAt": null,
        "defaultGearReward": 30,
        "normalTicketReward": 0,
        "missionProgress": { "completed": 3, "total": 5 }
      },
      {
        "stageNumber": 3,
        "rewardText": null,
        "isTriggered": false,
        "triggeredAt": null,
        "defaultGearReward": 80,
        "normalTicketReward": 3,
        "missionProgress": { "completed": 0, "total": 5 }
      }

  }
```

**구현 노트**

```jsx
1. 모든 부모 API는 child.parent_id == currentParentId 검증 필수
2. stageNumber는 1, 2, 3만 허용
3. rewardText는 null 허용, 값이 있으면 최대 100자
4. stage_completion_rewards row는 자녀별 1~3단계가 항상 존재하도록 생성 또는 upsert
5. isTriggered=true 이후 rewardText 수정 금지
```

### Service 로직

```java
@Service
@RequiredArgsConstructor
public class ParentDashboardService {

    private final ChildProfileRepository childRepo;
    private final MissionAttemptRepository missionAttemptRepo;
    private final MissionAnswerResultRepository answerResultRepo;
    private final PrivacyEventRepository privacyEventRepo;
    private final StreakRecordRepository streakRepo;

    // ─── 공통: 소유권 검증 (등 4개 엔드포인트에서 호출) ───
    private ChildProfile validateOwnership(String parentId, UUID childId) {
        ChildProfile child = childRepo.findById(childId)
            .orElseThrow(() -> new AImongException(ErrorCode.NOT_FOUND));
        if (!child.getParentId().equals(parentId)) {
            throw new AImongException(ErrorCode.FORBIDDEN); // 403
        }
        return child;
    }

    // ─── GET /summary ────────────────────────────
    public SummaryResponse getSummary(String parentId, UUID childId) {
        ChildProfile child = validateOwnership(parentId, childId);
        StreakRecord streak = streakRepo.findById(childId).orElseThrow();

        LocalDate weekStart = LocalDate.now(ZoneId.of("Asia/Seoul")).with(DayOfWeek.MONDAY);
        Instant weekStartInstant = weekStart.atStartOfDay(ZoneId.of("Asia/Seoul")).toInstant();

        // is_review=false, is_passed=true, set_id별 최초 완료만 집계
        int weeklyMissionCount = missionAttemptRepo.countWeeklyFirstCompletedMissions(childId, weekStartInstant);
        int totalMissionCount = missionAttemptRepo.countTotalFirstCompletedMissions(childId);

        return SummaryResponse.builder()
            .nickname(child.getNickname())
            .profileImageType(child.getProfileImageType())
            .totalXp(child.getTotalXp())
            .continuousDays(streak.getContinuousDays())
            .shieldCount(child.getShieldCount())
            .weeklyMissionCount(weeklyMissionCount)
            .totalMissionCount(totalMissionCount)
            .lastActiveAt(child.getLastActiveAt())
            .build();
    }

    // ─── GET /weekly-stats ──────────────────────────
    public WeeklyStatsResponse getWeeklyStats(String parentId, UUID childId) {
        validateOwnership(parentId, childId);

        LocalDate today = LocalDate.now(ZoneId.of("Asia/Seoul"));
        LocalDate weekStart = today.with(DayOfWeek.MONDAY);
        LocalDate weekEnd = today.with(DayOfWeek.SUNDAY);

        Instant from = weekStart.atStartOfDay(ZoneId.of("Asia/Seoul")).toInstant();
        Instant to = weekEnd.plusDays(1).atStartOfDay(ZoneId.of("Asia/Seoul")).toInstant();

        // JPQL: mission_attempts를 KST 날짜 기준으로 GROUP BY
        List<DailyStatDto> rawStats = missionAttemptRepo
            .findDailyStatsByChildIdBetween(childId, from, to);

        // 주중 7일 모두 마마 포함 (missing 일짜는 0으로 보완)
        List<DailyStatResponse> dailyStats = weekStart.datesUntil(weekEnd.plusDays(1))
            .map(date -> {
                DailyStatDto dto = rawStats.stream()
                    .filter(d -> d.getDate().equals(date))
                    .findFirst().orElse(DailyStatDto.empty(date));
                return DailyStatResponse.of(date, dto);
            }).toList();

        return WeeklyStatsResponse.builder()
            .weekStart(weekStart)
            .weekEnd(weekEnd)
            .totalWeeklyXp(dailyStats.stream().mapToInt(DailyStatResponse::getXpEarned).sum())
            .totalWeeklyMissions(dailyStats.stream().mapToInt(DailyStatResponse::getMissionCount).sum())
            .dailyStats(dailyStats)
            .build();
    }

    // ─── GET /privacy-log ─────────────────────────
    public PrivacyLogResponse getPrivacyLog(String parentId, UUID childId, int page, int size) {
        validateOwnership(parentId, childId);

        Instant weekStartInstant = LocalDate.now(ZoneId.of("Asia/Seoul"))
            .with(DayOfWeek.MONDAY)
            .atStartOfDay(ZoneId.of("Asia/Seoul")).toInstant();

        Pageable pageable = PageRequest.of(page, size,
            Sort.by(Sort.Direction.DESC, "detectedAt"));
        Page<PrivacyEvent> eventPage = privacyEventRepo.findByChildId(childId, pageable);

        long weeklyCount = privacyEventRepo.countByChildIdAndDetectedAtAfter(childId, weekStartInstant);

        List<PrivacyLogItem> events = eventPage.getContent().stream()
            .map(e -> new PrivacyLogItem(
                e.getDetectedType(),
                e.isMasked(),
                e.getDetectedAt()
            )).toList();

        return new PrivacyLogResponse(
            page,
            size,
            eventPage.getTotalElements(),
            eventPage.hasNext(),
            weeklyCount,
            events
        );
    }

    // ─── GET /weak-points ─────────────────────────
    public WeakPointsResponse getWeakPoints(String parentId, UUID childId, int page, int size) {
        validateOwnership(parentId, childId);

        Instant since = Instant.now().minus(30, ChronoUnit.DAYS);
        Pageable pageable = PageRequest.of(page, size);

        // 최종 submit으로 저장된 mission_answer_results 기반 문항 단위 오답률 계산 (복습 포함, check 결과 제외)
        Page<WeakPointDto> weakPoints = answerResultRepo.findWeakPointsByChildId(childId, since, pageable);

        return new WeakPointsResponse(
            page,
            size,
            weakPoints.getTotalElements(),
            weakPoints.hasNext(),
            "최근 30일",
            weakPoints.getContent()
        );
    }
}
```

### Repository 쿼리

```java
public interface MissionAttemptRepository extends JpaRepository<MissionAttempt, UUID> {

    @Query("""
        SELECT COUNT(DISTINCT a.missionId)
        FROM MissionAttempt a
        WHERE a.childId = :childId
          AND a.isReview = false
          AND a.isPassed = true
        """)
    int countTotalFirstCompletedMissions(@Param("childId") UUID childId);

    @Query("""
        SELECT COUNT(DISTINCT a.missionId)
        FROM MissionAttempt a
        WHERE a.childId = :childId
          AND a.isReview = false
          AND a.isPassed = true
          AND a.createdAt >= :after
        """)
    int countWeeklyFirstCompletedMissions(@Param("childId") UUID childId, @Param("after") Instant after);

public interface MissionAnswerResultRepository extends JpaRepository<MissionAnswerResult, UUID> {

    // 미션별 incorrectRate 계산 — 최종 submit 결과만 기준, 복습(is_review=true) 포함, check 결과 제외
    @Query("""
        SELECT new com.aimong.dto.WeakPointDto(
            m.missionId,
            m.title,
            m.stage,
            CAST(SUM(CASE WHEN r.isCorrect = false THEN 1 ELSE 0 END) AS double) / COUNT(r.resultId),
            COUNT(DISTINCT r.attemptId)
        )
        FROM MissionAnswerResult r
        JOIN Mission m ON r.missionId = m.missionId
        WHERE r.childId = :childId
          AND r.createdAt >= :since
        GROUP BY m.missionId, m.title, m.stage
        HAVING COUNT(r.resultId) > 0
        ORDER BY CAST(SUM(CASE WHEN r.isCorrect = false THEN 1 ELSE 0 END) AS double) / COUNT(r.resultId) DESC
        """)
    Page<WeakPointDto> findWeakPointsByChildId(
        @Param("childId") UUID childId,
        @Param("since") Instant since,
        Pageable pageable
    );
}
```
