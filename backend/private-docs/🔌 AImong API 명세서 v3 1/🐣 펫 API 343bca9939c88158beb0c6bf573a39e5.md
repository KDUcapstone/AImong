# 🐣 펫 API

## GET /pet

> 현재 장착 펫 + 보유 펫 전체 목록 조회
> 

**담당**: BE (문한일) | **인증**: CHILD

**Response 200**

```json
{
  "success": true,
  "data": {
    "equippedPet": {
      "id": "uuid",
      "petType": "pet_normal_001",
      "grade": "NORMAL",
      "xp": 95,
      "stage": "GROWTH",
      "mood": "HAPPY",
      "crownUnlocked": false,
      "crownType": null,
      "obtainedAt": "2026-03-25T10:00:00Z"
    },
    "pets": [
      {
        "id": "uuid",
        "petType": "pet_rare_003",
        "grade": "RARE",
        "xp": 0,
        "stage": "EGG",
        "mood": "IDLE",
        "crownUnlocked": true,
        "crownType": "gold",
        "obtainedAt": "2026-03-27T15:30:00Z"
      }
    ],
    "totalPetCount": 3
  }
}
```

> `equippedPet`이 null이면 FE에서 "펫을 장착해야 XP를 얻을 수 있어요!" 안내 표시
> 

> `mood` 허용 값: `HAPPY`, `IDLE`, `SAD_LIGHT`, `SAD_DEEP`
> 

> MVP에서는 스타터 가챠 후 첫 번째 펫 자동 장착. 이후 장착 펫 교체는 `PUT /pet/equip` 사용.
> 

**예외 처리**

| 상황 | HTTP | code | message |
| --- | --- | --- | --- |
| 인증 실패 | 401 | UNAUTHORIZED | 로그인이 필요합니다 |

## PUT /pet/equip

> 보유 펫 중 원하는 펫으로 장착 세팅 (교체)
> 

**담당**: BE (문한일) | **인증**: CHILD

> 🆕 **v1.6 신규**: 스타터 가챠 이후 다른 펫으로 교체할 때 호출합니다.
> 

**Request Body**

```json
{ "petId": "uuid" }
```

| 필드 | 타입 | 필수 | 유효성 |
| --- | --- | --- | --- |
| petId | string | ✅ | 본인이 보유한 펫의 UUID |

**Response 200**

```json
{
  "success": true,
  "data": {
    "equippedPetId": "uuid",
    "petType": "pet_rare_003",
    "grade": "RARE",
    "stage": "GROWTH"
  }
}
```

**예외 처리**

| 상황 | HTTP | code | message |
| --- | --- | --- | --- |
| petId 누락 | 400 | BAD_REQUEST | 장착할 펫을 선택해주세요 |
| 본인 보유 펫이 아님 | 403 | FORBIDDEN | 접근 권한이 없습니다 |
| petId 존재하지 않음 | 404 | NOT_FOUND | 펫을 찾을 수 없습니다 |

**구현 노트**

```jsx
1. pets WHERE id = petId AND child_id = 나 확인 (불일치 403)
2. child_profiles.equipped_pet_id = petId UPDATE
```

```java
// pets 테이블 매핑
@Entity @Table(name = "pets",
    uniqueConstraints = @UniqueConstraint(columnNames = {"child_id", "pet_type"}))
public class Pet {
    @Id @GeneratedValue(strategy = GenerationType.UUID)
    @Column(name = "pet_id")
    private UUID petId;

    @Column(name = "child_id", nullable = false)
    private UUID childId;

    @Column(name = "pet_type", nullable = false)
    private String petType;               // "pet_normal_001" 등

    @Column(name = "grade")
    @Enumerated(EnumType.STRING)
    private PetGrade grade;               // NORMAL, RARE, EPIC, LEGEND

    @Column(name = "stage")
    @Enumerated(EnumType.STRING)
    private PetStage stage;               // EGG, GROWTH, AIMONG

    @Column(name = "xp")
    private int xp = 0;                   // 단계별 성장 XP 누적치

    @Column(name = "crown_unlocked")
    private boolean crownUnlocked = false; // AIMONG 단계 도달 시 true

    @Column(name = "crown_type")
    private String crownType;              // "gold", "silver" 등 또는 null

    @Column(name = "is_equipped")
    private boolean isEquipped = false;   // 이 커럼대신 child_profiles.equipped_pet_id 사용

    @Column(name = "obtained_at")
    private Instant obtainedAt;            // 가챨 또는 교환 시각
}

// pet_fragments 테이블 (PK: child_id + grade)
@Entity @Table(name = "pet_fragments",
    uniqueConstraints = @UniqueConstraint(columnNames = {"child_id", "grade"}))
public class PetFragment {
    @Id @GeneratedValue(strategy = GenerationType.UUID)
    private UUID id;

    @Column(name = "child_id")
    private UUID childId;

    @Column(name = "grade")
    @Enumerated(EnumType.STRING)
    private PetGrade grade;

    @Column(name = "count")
    private int count = 0;                // 보유 조각 수
}

// child_profiles 에 추가 필드
@Column(name = "equipped_pet_id")
private UUID equippedPetId;               // 현재 장착 펫 ID (FK → pets.pet_id)

@Column(name = "gacha_pull_count")
private int gachaPullCount = 0;           // 전체 누적 가챨회수

@Column(name = "sr_miss_count")
private int srMissCount = 0;              // 스레이다운 기준 연속 비시효돈 횟수
```

### GET /pet — 조회 로직

```java
@Service @RequiredArgsConstructor
public class PetService {

    public PetListResponse getPets(UUID childId) {
        ChildProfile profile = profileRepo.findById(childId).orElseThrow();
        UUID equippedId = profile.getEquippedPetId();

        List<Pet> all = petRepo.findByChildIdOrderByObtainedAtDesc(childId);
        PetDto equippedDto = all.stream()
            .filter(p -> p.getPetId().equals(equippedId))
            .findFirst()
            .map(PetDto::from)
            .orElse(null);

        List<PetDto> otherPets = all.stream()
            .filter(p -> !p.getPetId().equals(equippedId))
            .map(PetDto::from)
            .toList();

        return new PetListResponse(equippedDto, otherPets, all.size());
    }
}
```

### PUT /pet/equip — 펫 장착 교체

```java
@Transactional
public EquipResponse equipPet(UUID childId, UUID petId) {
    Pet pet = petRepo.findById(petId)
        .orElseThrow(() -> new NotFoundException("펫"));

    // 본인 펫인지 확인
    if (!pet.getChildId().equals(childId))
        throw new ForbiddenException();

    // child_profiles.equipped_pet_id 업데이트
    ChildProfile profile = profileRepo.findById(childId).orElseThrow();
    profile.setEquippedPetId(petId);

    return new EquipResponse(petId, pet.getPetType(), pet.getGrade(), pet.getStage());
}
```

### 펫 성장 처리 — PetService.addXpAndEvolve()

```java
/**
 * 미션 채점 후 장착 펫의 현재 XP를 기준으로 진화 여부만 판정
 * XP 적립 자체는 반드시 XpService.grant()에서 한 번만 처리한다.
 * 성장 단계별 XP 기준:
 *   EGG   -> GROWTH : NORMAL=10, RARE=12, EPIC=15, LEGEND=20
 *   GROWTH -> AIMONG: NORMAL=30, RARE=36, EPIC=45, LEGEND=60
 */
@Transactional
public List<RewardDto> addXpAndEvolve(UUID childId) {
    List<RewardDto> rewards = new ArrayList<>();
    Pet pet = petRepo.findEquippedByChildId(childId).orElse(null);
    if (pet == null) return rewards;

    int threshold = getEvolutionThreshold(pet.getGrade(), pet.getStage());

    if (pet.getStage() != PetStage.AIMONG && pet.getXp() >= threshold) {
        PetStage next = pet.getStage() == PetStage.EGG ? PetStage.GROWTH : PetStage.AIMONG;
        pet.setStage(next);
        pet.setXp(0); // 단계 진입 시 XP 리셋

        if (next == PetStage.AIMONG) {
            pet.setCrownUnlocked(true);
            // AIMONG 단계 도달 미션 펫 등급별 티켓 보상
            TicketType reward = switch (pet.getGrade()) {
                case NORMAL -> TicketType.RARE;   // RARE 티켓 +1
                case RARE   -> TicketType.EPIC;   // EPIC 티켓 +1
                case EPIC   -> TicketType.EPIC;   // EPIC 티켓 +2
                case LEGEND -> TicketType.EPIC;   // EPIC 티켓 +3
            };
            int count = pet.getGrade() == PetGrade.LEGEND ? 3
                      : pet.getGrade() == PetGrade.EPIC   ? 2 : 1;
            for (int i = 0; i < count; i++)
                ticketRepo.save(new Ticket(childId, reward));
            rewards.add(new RewardDto("TICKET", reward.name(), count, "PET_EVOLUTION"));
        }
    }
    return rewards;
}

private int getEvolutionThreshold(PetGrade grade, PetStage current) {
    return switch (current) {
        case EGG    -> switch (grade) {
            case NORMAL -> 10; case RARE -> 12; case EPIC -> 15; case LEGEND -> 20;
        };
        case GROWTH -> switch (grade) {
            case NORMAL -> 30; case RARE -> 36; case EPIC -> 45; case LEGEND -> 60;
        };
        default -> Integer.MAX_VALUE;
    };
}
```

### ⚠️ 구현 주의사항

```jsx
1. equipped_pet_id 는 child_profiles 테이블에 저장—pets.is_equipped 컴럼은 사용 안 함
   (GET /pet 시 child_profiles.equipped_pet_id 기준으로 판단)

2. 펫 XP는 xpService.grant() 호출 시 자동 누적됨 (공통 XP 함수 참고)
   addXpAndEvolve()에서는 XP를 다시 더하지 말고 현재 누적 XP로 진화만 판정

3. 펫 성장 시 XP = 0 리셋 (동일 pet_id가 유지되며 stage만 변경됨)
   — 미션 1회 성공당 펫 XP는 정확히 1번만 반영되어야 함

4. getEvolutionThreshold()를 Enum에 매핑하는 방식 권장
   (PetGrade, PetStage 조합으로 DB나 코드에 명시적 정의)
```
