# 🛡️ 개인정보 API

## POST /privacy/event

> 개인정보 감지 이벤트 기록 + 부모 FCM 비동기 발송
> 

**담당**: BE (문한일) | **인증**: CHILD

> ⚠️ FE에서 온디바이스(ML Kit + Regex)로 감지 후 호출. 원문 텍스트는 절대 전송/저장 안 함.
> 

**Request Body**

```json
{
  "detectedType": "NAME",
  "masked": true
}
```

| detectedType | 설명 |
| --- | --- |
| NAME | 이름 감지 |
| SCHOOL | 학교명 감지 |
| AGE | 나이/학년 감지 |
| PHONE | 전화번호 감지 |
| EMAIL | 이메일 감지 |
| ADDRESS | 주소 감지 |
| DATE | 날짜(생년월일 추정) |
| URL | URL 감지 |

**Response 200**

```json
{ "success": true, "data": { "recorded": true } }
```

**예외 처리**

| 상황 | HTTP | code | message |
| --- | --- | --- | --- |
| detectedType 누락 | 400 | BAD_REQUEST | 감지 유형을 입력해주세요 |
| 유효하지 않은 detectedType 값 | 400 | BAD_REQUEST | 올바른 감지 유형이 아닙니다 |

**구현 노트**

```jsx
1. privacy_events INSERT
   { child_id, detected_type, masked }  ← 원문(텍스트) 절대 저장 안 함

2. FCM 발송 (비동기 @Async)
   - 1단계: 오늘 해당 자녀의 PRIVACY_ALERT 발송 횟수 < 5회
   - 2단계: 오늘 해당 부모 계정의 전체 FCM 발송 횟수 < 5회
   - 초과 시: 큐 적재 후 다음 발송 시 묶음 발송
   - 원문 내용 부모에게도 절대 공유 안 함

   FCM Payload:
   {
     "title": "개인정보 입력 감지",
     "body": "자녀가 AI에게 개인정보를 입력하려 했어요. 대화해보세요 😊",
     "data": { "type": "PRIVACY_ALERT", "childId": "...", "detectedType": "NAME" }
   }
```

## 🛠️ Spring Boot 구현 가이드

### 관련 Entity & DB 구조

```java
// privacy_events 테이블 (원문 원본 전대 저장 금지)
@Entity @Table(name = "privacy_events")
public class PrivacyEvent {
    @Id @GeneratedValue(strategy = GenerationType.UUID)
    @Column(name = "event_id")
    private UUID eventId;

    @Column(name = "child_id", nullable = false)
    private UUID childId;

    @Column(name = "detected_type")
    @Enumerated(EnumType.STRING)
    private DetectedType detectedType;    // NAME, SCHOOL, AGE, PHONE, EMAIL, ADDRESS, DATE, URL

    @Column(name = "masked")
    private boolean masked;               // FE에서 마스킹 여부 (서버는 신뢰 안 함)

    @Column(name = "detected_at")
    private Instant detectedAt;           // UTC 저장, 응답 시 ISO-8601 포맷

    // ❌ 저장 금지 필드: original_text, masked_text, ip_address 등 일체 금지!
}

// fcm_send_log 테이블 (발송 횟수 제한 추적용)
@Entity @Table(name = "fcm_send_log")
public class FcmSendLog {
    @Id @GeneratedValue(strategy = GenerationType.UUID)
    private UUID id;

    @Column(name = "parent_id")        private String parentId;
    @Column(name = "child_id")         private UUID childId;
    @Column(name = "send_type")        private String sendType;  // "PRIVACY_ALERT"
    @Column(name = "sent_at")          private Instant sentAt;   // UTC
    @Column(name = "date")             private LocalDate date;   // KST
}
```

### POST /privacy/event — 서비스 로직

```java
@Service @RequiredArgsConstructor
public class PrivacyService {
    private final PrivacyEventRepository eventRepo;
    private final FcmSendLogRepository fcmLogRepo;
    private final FcmService fcmService;        // @Async 비동기 FCM 발송
    private final ChildProfileRepository profileRepo;
    private final ParentAccountRepository parentRepo;

    @Transactional
    public PrivacyResponse record(UUID childId, DetectedType detectedType, boolean masked) {
        // 1. 감지 이벤트 저장 (원문 절대 미저장)
        PrivacyEvent event = PrivacyEvent.builder()
            .childId(childId)
            .detectedType(detectedType)
            .masked(masked)
            .detectedAt(Instant.now())
            .build();
        eventRepo.save(event);

        // 2. FCM 발송 비동기 실행
        sendFcmAsync(childId);

        return new PrivacyResponse(true);
    }

    @Async  // 발송 실패가 응답에 영향 없도록 비동기 실행
    public void sendFcmAsync(UUID childId) {
        LocalDate today = LocalDate.now(ZoneId.of("Asia/Seoul"));
        ChildProfile child = profileRepo.findById(childId).orElse(null);
        if (child == null) return;

        // 자녀별 일일 발송 횟수 확인 (< 5회)
        long childAlertCount = fcmLogRepo.countByChildIdAndSendTypeAndDate(
            childId, "PRIVACY_ALERT", today);
        if (childAlertCount >= 5) return;

        // 부모별 일일 전체 FCM 발송 횟수 확인 (< 5회)
        String parentId = child.getParentId();
        long parentTotalCount = fcmLogRepo.countByParentIdAndDate(parentId, today);
        if (parentTotalCount >= 5) return;

        // 부모 FCM 토큰 조회
        ParentAccount parent = parentRepo.findById(parentId).orElse(null);
        if (parent == null || parent.getFcmToken() == null) return;

        // FCM 발송
        boolean sent = fcmService.send(parent.getFcmToken(), FcmPayload.builder()
            .title("개인정보 입력 감지")
            .body("자녀가 AI에게 개인정보를 입력하려 했어요. 대화해보세요 😊")
            .data(Map.of("type", "PRIVACY_ALERT", "childId", childId.toString()))
            .build());

        if (sent) {
            fcmLogRepo.save(FcmSendLog.builder()
                .parentId(parentId).childId(childId)
                .sendType("PRIVACY_ALERT")
                .sentAt(Instant.now()).date(today).build());
        }
    }
}
```

### FcmService — Firebase Cloud Messaging 연동

```java
@Service @RequiredArgsConstructor
public class FcmService {
    private final FirebaseMessaging messaging;  // Firebase Admin SDK Bean

    public boolean send(String token, FcmPayload payload) {
        try {
            Message msg = Message.builder()
                .setToken(token)
                .setNotification(Notification.builder()
                    .setTitle(payload.getTitle())
                    .setBody(payload.getBody()).build())
                .putAllData(payload.getData())
                .build();
            messaging.send(msg);
            return true;
        } catch (FirebaseMessagingException e) {
            log.warn("FCM 발송 실패: token={}, error={}", token, e.getMessagingErrorCode());
            return false; // 실패해도 200 반환
        }
    }
}

// FirebaseConfig.java
@Configuration
public class FirebaseConfig {
    @Bean
    public FirebaseApp firebaseApp() throws IOException {
        GoogleCredentials creds = GoogleCredentials
            .fromStream(new ClassPathResource("firebase-service-account.json").getInputStream());
        return FirebaseApp.initializeApp(
            FirebaseOptions.builder().setCredentials(creds).build());
    }
    @Bean
    public FirebaseMessaging firebaseMessaging(FirebaseApp app) {
        return FirebaseMessaging.getInstance(app);
    }
}
```

### ⚠️ 구현 주의사항

```
1. 원문 텍스트 절대 저장 금지:
   PrivacyEvent에 original_text, masked_text 필드 자체를 만들면 안 됨
   (저장 가능한 것: detected_type, masked 보리언, detected_at시각만)

2. FCM 발송 실패 시 200 반환:
   발송 실패가 API 응답에 영향 없도록 @Async로 비동기 실행

3. FCM 일일 한도 (5회):
   자녀별 5회 + 부모별 5회 두 조건 모두 체크

4. 부모 FCM 토큰 등록이 없으면 발송 스킵 (null 처리)

5. @Async 활성화: @EnableAsync 없으면 동기 실행됩니다
   — @SpringBootApplication 또는 @Configuration 클래스에 @EnableAsync 필수!
```
