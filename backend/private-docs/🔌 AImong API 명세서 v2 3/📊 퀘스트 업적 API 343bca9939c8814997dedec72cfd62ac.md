# 📊 퀘스트 / 업적 API

> 🆕 **v2.0 반영**: 퀘스트/업적의 `MISSION_*` 명칭은 사용자 문구 호환을 위해 유지하지만, 내부 기준은 일반 모드로 통과한 `setId` 수입니다.
> 

## GET /quests/daily

> 오늘의 데일리 퀘스트 목록 + 진행 현황
> 

**담당**: BE (문한일) | **인증**: CHILD

> 🆕 **v1.1 변경**: `claimType` 필드 추가 (AUTO / MANUAL). `MISSION_1`, `CHAT_GPT`는 AUTO 처리.
> 

> ⚠️ 복습 제출은 퀘스트/업적 진행도에 반영하지 않습니다. 퀘스트/업적 갱신은 일반 모드 학습 세트 submit 통과와 GPT 성공 호출만 대상으로 합니다.
>

**퀘스트 타입별 규칙**

## POST /quests/claim

> 완료된 퀘스트 보상 수령 (MANUAL 퀘스트만 해당)
> 

**담당**: BE (문한일) | **인증**: CHILD

> 🆕 **v1.1 변경**: AUTO 퀘스트(`MISSION_1`, `CHAT_GPT`)는 이 API로 수령 불가. 응답이 `rewards[]` 배열로 변경.
> 

**Request Body**

```json
{ "questType": "XP_20", "period": "daily" }
```

**Response 200**

```json
{
  "success": true,
  "data": {
    "rewards": [
      { "type": "TICKET", "ticketType": "NORMAL", "count": 1, "reason": "DAILY_QUEST_XP_20" }
    ],
    "remainingTickets": { "normal": 3, "rare": 0, "epic": 0 }
  }
}
```

**예외 처리**

| 상황 | HTTP | code | message |
| --- | --- | --- | --- |
| AUTO 퀘스트 수령 시도 | 400 | BAD_REQUEST | 자동 지급 퀘스트는 수령 API를 호출할 수 없어요 |
| 퀘스트 미완료 상태에서 수령 시도 | 400 | BAD_REQUEST | 아직 완료되지 않은 퀘스트예요 |
| 이미 보상 수령함 | 409 | CONFLICT | 이미 보상을 받았어요 |

### 관련 Entity & DB 구조

```java
// quest_definitions 테이블 (정적 데이터 — 코드나 초기 DB로 관리)
// questType, period, label, claimType, requiredValue, rewardType, rewardAmount
// 예: MISSION_1, daily, "미션 1개 완료", AUTO, 1, NONE, 0
// 예: XP_20,     daily, "XP 20 획득",    MANUAL, 20, TICKET_NORMAL, 1

// daily_quest_progress 테이블 (PK: child_id + quest_type + date)
@Entity @Table(name = "daily_quest_progress",
    uniqueConstraints = @UniqueConstraint(
        columnNames = {"child_id", "quest_type", "date"}))
public class DailyQuestProgress {
    @Id @GeneratedValue(strategy = GenerationType.UUID)
    private UUID id;

    @Column(name = "child_id")       private UUID childId;
    @Column(name = "quest_type")     private String questType;    // MISSION_1, XP_20, ALL_3 ...
    @Column(name = "date")           private LocalDate date;      // KST
    @Column(name = "current_value")  private int currentValue = 0; // 현재 진행 값
    @Column(name = "completed")      private boolean completed = false;
    @Column(name = "reward_claimed") private boolean rewardClaimed = false;
}

// weekly_quest_progress 테이블 (PK: child_id + quest_type + week_start)
@Entity @Table(name = "weekly_quest_progress",
    uniqueConstraints = @UniqueConstraint(
        columnNames = {"child_id", "quest_type", "week_start"}))
public class WeeklyQuestProgress {
    @Id @GeneratedValue(strategy = GenerationType.UUID)
    private UUID id;

    @Column(name = "child_id")       private UUID childId;
    @Column(name = "quest_type")     private String questType;
    @Column(name = "week_start")     private LocalDate weekStart; // KST 월요일
    @Column(name = "current_value")  private int currentValue = 0;
    @Column(name = "completed")      private boolean completed = false;
    @Column(name = "reward_claimed") private boolean rewardClaimed = false;
}

// achievement_progress 테이블 (PK: child_id + achievement_type)
@Entity @Table(name = "achievement_progress",
    uniqueConstraints = @UniqueConstraint(
        columnNames = {"child_id", "achievement_type"}))
public class AchievementProgress {
    @Id @GeneratedValue(strategy = GenerationType.UUID)
    private UUID id;

    @Column(name = "child_id")           private UUID childId;
    @Column(name = "achievement_type")   private String achievementType; // MISSION_10, XP_100 ...
    @Column(name = "current_value")      private int currentValue = 0;
    @Column(name = "completed")          private boolean completed = false;
    @Column(name = "completed_at")       private LocalDate completedAt;
}
```

### QuestService.update() — 퀘스트 진행도 갱신 연동

```java
/**
 * 일반 모드 미션 제출, GPT 호출 성공 후 모든 수치 업데이트
 * 복습 제출(review)은 quest/achievement 갱신 대상이 아니다.
 */
@Transactional
public void update(UUID childId) {
    LocalDate today = LocalDate.now(ZoneId.of("Asia/Seoul"));
    LocalDate weekStart = today.with(DayOfWeek.MONDAY);
    ChildProfile profile = profileRepo.findById(childId).orElseThrow();

    Instant todayStart = today.atStartOfDay(ZoneId.of("Asia/Seoul")).toInstant();
    Instant tomorrowStart = today.plusDays(1).atStartOfDay(ZoneId.of("Asia/Seoul")).toInstant();
    Instant weekStartInstant = weekStart.atStartOfDay(ZoneId.of("Asia/Seoul")).toInstant();

    // 일반 모드 완료만 집계
    int todaySets = missionAttemptRepo
        .countDistinctSetIdByChildIdAndIsReviewFalseAndIsPassedTrueAndCreatedAtBetween(
            childId, todayStart, tomorrowStart);
    int weeklySets = missionAttemptRepo
        .countDistinctSetIdByChildIdAndIsReviewFalseAndIsPassedTrueAndCreatedAtAfter(
            childId, weekStartInstant);

    int todayChats = chatUsageRepo
        .findByChildIdAndDate(childId, today)
        .map(ChatUsage::getCount).orElse(0);
    int weeklyChats = chatUsageRepo
        .sumCountByChildIdAndDateBetween(childId, weekStart, today)
        .orElse(0);

    int todayXp = profile.getTodayXp();
    int weeklyXp = profile.getWeeklyXp();

    Map<String, Integer> dailyValues = Map.of(
        "MISSION_1", todaySets,
        "XP_20", todayXp,
        "CHAT_GPT", todayChats
    );
    Map<String, Integer> dailyRequired = Map.of(
        "MISSION_1", 1, "XP_20", 20, "CHAT_GPT", 1
    );

    for (Map.Entry<String, Integer> e : dailyValues.entrySet()) {
        String type = e.getKey();
        int val = e.getValue();
        DailyQuestProgress dq = dailyQuestRepo
            .findByChildIdAndQuestTypeAndDate(childId, type, today)
            .orElseGet(() -> DailyQuestProgress.builder()
                .childId(childId).questType(type).date(today).build());
        dq.setCurrentValue(val);
        if (!dq.isCompleted() && val >= dailyRequired.get(type)) {
            dq.setCompleted(true);
            if (type.equals("MISSION_1") || type.equals("CHAT_GPT")) {
                dq.setRewardClaimed(true); // AUTO 퀘스트
            }
        }
        dailyQuestRepo.save(dq);
    }

    long completedCount = dailyQuestRepo.countByChildIdAndDateAndCompleted(childId, today, true);
    DailyQuestProgress all3 = dailyQuestRepo
        .findByChildIdAndQuestTypeAndDate(childId, "ALL_3", today)
        .orElseGet(() -> DailyQuestProgress.builder()
            .childId(childId).questType("ALL_3").date(today).build());
    all3.setCurrentValue((int) completedCount);
    if (!all3.isCompleted() && completedCount >= 3) all3.setCompleted(true);
    dailyQuestRepo.save(all3);

    Map<String, Integer> weeklyValues = Map.of(
        "XP_100", weeklyXp,
        "MISSION_5", weeklySets,
        "CHAT_3", weeklyChats
    );
    Map<String, Integer> weeklyRequired = Map.of(
        "XP_100", 100, "MISSION_5", 5, "CHAT_3", 3
    );

    for (Map.Entry<String, Integer> e : weeklyValues.entrySet()) {
        String type = e.getKey();
        int val = e.getValue();
        WeeklyQuestProgress wq = weeklyQuestRepo
            .findByChildIdAndQuestTypeAndWeekStart(childId, type, weekStart)
            .orElseGet(() -> WeeklyQuestProgress.builder()
                .childId(childId).questType(type).weekStart(weekStart).build());
        wq.setCurrentValue(val);
        if (!wq.isCompleted() && val >= weeklyRequired.get(type)) {
            wq.setCompleted(true);
        }
        weeklyQuestRepo.save(wq);
    }
}
```

### POST /quests/claim — 보상 수령 로직

```java
@Transactional
public ClaimResponse claim(UUID childId, String questType, String period) {
    LocalDate today = LocalDate.now(ZoneId.of("Asia/Seoul"));

    if ("daily".equals(period)) {
        DailyQuestProgress dq = dailyQuestRepo
            .findByChildIdAndQuestTypeAndDate(childId, questType, today)
            .orElseThrow(() -> new BadRequestException("아직 완료되지 않은 퀘스트예요"));

        // AUTO 퀘스트 새한
        if (List.of("MISSION_1", "CHAT_GPT").contains(questType))
            throw new BadRequestException("자동 지급 퀘스트는 수령 API를 호출할 수 없어요");
        if (!dq.isCompleted())
            throw new BadRequestException("아직 완료되지 않은 퀘스트예요");
        if (dq.isRewardClaimed())
            throw new ConflictException("CONFLICT", "이미 보상을 받았어요");

        dq.setRewardClaimed(true);
        return grantQuestReward(childId, questType, period);
    } else {
        LocalDate weekStart = today.with(DayOfWeek.MONDAY);
        WeeklyQuestProgress wq = weeklyQuestRepo
            .findByChildIdAndQuestTypeAndWeekStart(childId, questType, weekStart)
            .orElseThrow(() -> new BadRequestException("아직 완료되지 않은 퀘스트예요"));
        if (!wq.isCompleted())
            throw new BadRequestException("아직 완료되지 않은 퀘스트예요");
        if (wq.isRewardClaimed())
            throw new ConflictException("CONFLICT", "이미 보상을 받았어요");
        wq.setRewardClaimed(true);
        return grantQuestReward(childId, questType, period);
    }
}

private ClaimResponse grantQuestReward(UUID childId, String questType, String period) {
    // quest_definitions에서 보상 정보 조회
    QuestDefinition def = questDefRepo.findByQuestTypeAndPeriod(questType, period);
    List<RewardDto> rewards = new ArrayList<>();
    if (def.getRewardType().startsWith("TICKET_")) {
        TicketType type = TicketType.valueOf(def.getRewardType().replace("TICKET_", ""));
        for (int i = 0; i < def.getRewardAmount(); i++)
            ticketRepo.save(new Ticket(childId, type));
        rewards.add(new RewardDto("TICKET", type.name(), def.getRewardAmount(),
            "QUEST_" + questType));
    }
    Map<String, Long> remaining = ticketRepo.countByChildIdGroupByType(childId);
    return new ClaimResponse(rewards, remaining);
}
```

### AchievementService.check() — 업적 체크

```java
@Transactional
public void check(UUID childId) {
    ChildProfile profile = profileRepo.findById(childId).orElseThrow();
    int totalCompletedSets = missionAttemptRepo
        .countDistinctSetIdByChildIdAndIsReviewFalseAndIsPassed(childId, true);

    Map<String, Integer> values = Map.of(
        "MISSION_10",  totalCompletedSets,
        "MISSION_30",  totalCompletedSets,
        "XP_100",      profile.getTotalXp(),
        "XP_500",      profile.getTotalXp()
    );
    Map<String, Integer> required = Map.of(
        "MISSION_10", 10, "MISSION_30", 30,
        "XP_100", 100, "XP_500", 500
    );

    for (Map.Entry<String, Integer> e : values.entrySet()) {
        AchievementProgress ap = achievementRepo
            .findByChildIdAndAchievementType(childId, e.getKey())
            .orElseGet(() -> AchievementProgress.builder()
                .childId(childId).achievementType(e.getKey()).build());
        ap.setCurrentValue(e.getValue());
        if (!ap.isCompleted() && e.getValue() >= required.get(e.getKey())) {
            ap.setCompleted(true);
            ap.setCompletedAt(LocalDate.now(ZoneId.of("Asia/Seoul")));
        }
        achievementRepo.save(ap);
    }
}
```

### ⚠️ 구현 주의사항

```jsx
1. AUTO 퀘스트(MISSION_1, CHAT_GPT)는 claim API 호출 목록에 없는지 확인을 코드로 작성을
   — List.of("") contains() 스일로 판정 후 400

2. DailyQuestProgress는 UPSERT 패턴:
   findBy...().orElseGet(builder) — 난팬 없는 날대 원하는 progress를 엄대로 받아도 NPE 없음

3. questService.update() 는 일반 모드 학습 세트 submit 통과, GPT 호출 성공 후마다 호출
   — 복습 제출(review)과 실패 제출에서는 호출하지 않음
   — 같은 트랜잭션 내에서 수행해야 실패 시 함께 롤백

4. ALL_3 퀘스트: 데일리 3개 퀘스트의 completed를 COUNT
   — AUTO 퀘스트(MISSION_1, CHAT_GPT)도 completed=true일 때 포함
```
