# 📋 개요

이 문서는 AImong 프로젝트를 로컬에서 실행하거나 서버에 배포할 때 필요한 **모든 환경 변수**를 정리한 명세서입니다.

새 팀원이 개발 환경을 세팅할 때, 또는 서버 배포 시 이 문서를 기준으로 환경 변수를 설정하세요.

# 🖥️ 백엔드 (Spring Boot)

## 파일 위치

`backend/src/main/resources/application-local.yml` 또는 OS 환경 변수

> `application-local.yml`은 반드시 `.gitignore`에 포함되어 있어야 합니다.
> 

## 환경 변수 목록

| 변수명 | 설명 | 예시 형식 | 발급처 |
| --- | --- | --- | --- |
| `SUPABASE_URL` | Supabase 프로젝트 URL | `https://xxxx.supabase.co` | Supabase 대시보드 → Project Settings → API |
| `SUPABASE_KEY` | Supabase service_role 키 (서버 전용) | `eyJhbGci...` | Supabase 대시보드 → Project Settings → API |
| `SUPABASE_ANON_KEY` | Supabase anon 키 (공개용) | `eyJhbGci...` | Supabase 대시보드 → Project Settings → API |
| `OPENAI_API_KEY` | OpenAI GPT API 키 | `sk-proj-...` | [platform.openai.com](http://platform.openai.com) → API Keys |
| `FIREBASE_CREDENTIAL_PATH` | Firebase Admin SDK 서비스 계정 JSON 파일 경로 | `classpath:firebase-adminsdk.json` | Firebase 콘솔 → 프로젝트 설정 → 서비스 계정 |
| `CHILD_SESSION_SECRET` | 자녀 세션 토큰 서명 비밀 키 (32자 이상 랜덤 문자열) | `your-secret-key-here` | 직접 생성 (openssl rand -base64 32) |
| `SERVER_PORT` | 서버 포트 (기본값 8080) | `8080` | 팀 내 협의 |
| `JVM_TIMEZONE` | JVM 타임존 (반드시 Asia/Seoul) | `Asia/Seoul` | 고정값 |

## application-local.yml 예시 템플릿

```yaml
supabase:
  url: ${SUPABASE_URL}
  key: ${SUPABASE_KEY}
  anon-key: ${SUPABASE_ANON_KEY}

openai:
  api-key: ${OPENAI_API_KEY}
  model: gpt-5-mini

firebase:
  credential-path: ${FIREBASE_CREDENTIAL_PATH}

child-session:
  secret: ${CHILD_SESSION_SECRET}
  expire-hours: 720

server:
  port: ${SERVER_PORT:8080}

spring:
  jpa:
    hibernate:
      ddl-auto: validate
```

## Firebase Admin SDK 설정 방법

1. Firebase 콘솔([console.firebase.google.com](http://console.firebase.google.com)) 접속
2. 프로젝트 설정 → 서비스 계정 탭
3. **새 비공개 키 생성** 버튼 클릭 → JSON 파일 다운로드
4. 파일명을 `firebase-adminsdk.json`으로 변경
5. `backend/src/main/resources/` 아래에 저장
6. `.gitignore`에 `**/firebase-adminsdk.json` 추가 확인

# 📱 프론트엔드 (Android / Kotlin)

## 파일 위치

`android/local.properties` 및 `android/app/google-services.json`

> 두 파일 모두 반드시 `.gitignore`에 포함되어 있어야 합니다.
> 

## 환경 변수 목록

| 변수명 | 파일 | 설명 | 발급처 |
| --- | --- | --- | --- |
| `BASE_URL` | `local.properties` | 백엔드 API 서버 주소 | 팀 내 협의 |
| `GOOGLE_WEB_CLIENT_ID` | `local.properties` | Firebase Google 로그인용 Web Client ID | Firebase 콘솔 → 인증 → 로그인 제공업체 → Google → 웹 클라이언트 ID |
| `google-services.json` | `app/` 폴더 직접 배치 | Firebase 프로젝트 연결 설정 파일 | Firebase 콘솔 → 프로젝트 설정 → 내 앱 → google-services.json 다운로드 |

## [local.properties](http://local.properties) 예시 템플릿

```jsx
# Android SDK 경로 (자동 생성)
sdk.dir=/Users/{이름}/Library/Android/sdk

# AImong 커스텀 환경 변수
# Android 에뮬레이터 기준. 실기기는 http://{내IP}:8080/ 사용
BASE_URL=http://10.0.2.2:8080/
GOOGLE_WEB_CLIENT_ID=123456789-xxxx.apps.googleusercontent.com
```

## build.gradle.kts에서 BuildConfig로 주입하는 방법

```kotlin
// android/app/build.gradle.kts
android {
    defaultConfig {
        val localProps = java.util.Properties().apply {
            load(rootProject.file("local.properties").inputStream())
        }
        buildConfigField("String", "BASE_URL", "\"${localProps["BASE_URL"]}\"")
        buildConfigField("String", "GOOGLE_WEB_CLIENT_ID", "\"${localProps["GOOGLE_WEB_CLIENT_ID"]}\"")
    }
}
```

# 🌿 환경별 설정 요약

| 환경 | BASE_URL (FE) | SERVER_PORT (BE) | DB |
| --- | --- | --- | --- |
| **로컬** | `http://10.0.2.2:8080/` (에뮬레이터) 또는 `http://{내IP}:8080/` (실기기) | 8080 | Supabase (개발 프로젝트) |
| **개발 서버** | `https://dev-api.aimong.com/` | 8080 | Supabase (개발 프로젝트) |
| **프로덕션** | `https://api.aimong.com/` | 8080 | Supabase (프로덕션 프로젝트) |

> 에뮬레이터에서 로컬 서버 접근 시 `localhost` 대신 `10.0.2.2`를 사용해야 합니다.

# 🚨 보안 주의사항

- `application-local.yml`, `firebase-adminsdk.json`, `local.properties`, `google-services.json`은 **절대 Git에 커밋하지 마세요**
- `.gitignore` 설정 확인 필수:

```
# backend/.gitignore
application-local.yml
src/main/resources/firebase-adminsdk.json

# android/.gitignore
local.properties
app/google-services.json
```

- `SUPABASE_KEY` (service_role)는 서버에서만 사용하고, 클라이언트(Android)에 절대 포함하지 마세요
- `OPENAI_API_KEY`가 노출되면 즉시 [platform.openai.com](http://platform.openai.com)에서 재발급하세요
